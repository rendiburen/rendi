Struktur file:
- index.html / login.html : halaman login
- dashboard.html          : dashboard menu + greeting waktu lokal
- tracking.html           : pencarian Delivery Order
- stok.html               : data bahan ajar dinamis + tambah baris DOM
- laporan.html            : monitoring dan rekap
- histori.html            : histori transaksi
- css/style.css           : desain tampilan
- js/data.js              : data dummy dari tugas
- js/script.js            : interaksi DOM, validasi, modal, tracking
