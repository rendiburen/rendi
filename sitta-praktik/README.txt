SITTA Praktik 1 - Website Pemesanan Bahan Ajar UT

Cara menjalankan:
1. Ekstrak file ZIP ini.
2. Buka index.html di browser.
3. Login dengan salah satu akun dummy:
   - admin@ut.ac.id / admin123
   - rina@ut.ac.id / rina123
   - agus@ut.ac.id / agus123

Fitur utama:
- Halaman login dengan validasi email/password, alert error, modal lupa password, dan modal daftar.
- Dashboard dengan menu navigasi, dropdown laporan, greeting berdasarkan waktu lokal, dan ringkasan data.
- Tracking pengiriman berdasarkan Nomor Delivery Order: 2023001234 dan 2023005678.
- Informasi stok bahan ajar yang ditampilkan dinamis dari js/data.js.
- Tambah baris stok baru menggunakan JavaScript DOM.
- Halaman laporan dan histori transaksi sebagai pelengkap menu.

Struktur:
- index.html
- dashboard.html
- tracking.html
- stok.html
- laporan.html
- histori.html
- css/style.css
- js/data.js
- js/script.js
- img/cover bahan ajar

Catatan video penjelasan:
Jelaskan struktur folder, fungsi login, validasi form, penggunaan data dummy, DOM render table, pencarian tracking, penambahan stok, dan desain responsive.
